# Security Policy

Do not publish secrets or production data in issues, pull requests, logs, screenshots, or example files.

Sensitive examples include:

- Source upload keys.
- Magic-link or mail provider credentials.
- Database passwords.
- Portainer/Plesk webhook URLs.
- Session secrets.
- Call audio that should not be public.
- Database exports or node volumes.

Report sensitive security concerns privately to `info@projectseven.us`.
